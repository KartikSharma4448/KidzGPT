# 🌍 KidzGPT — Foreign/Global Course Syllabus
# (India ke Students ke liye — Korea/China/Finland Style Learning)

## Concept:
- India ka baccha apni language (Hindi/English) mein seekhega
- Content Korea/China/Finland style hoga — skill-based, practical, interactive
- Foreign languages OPTIONAL hain (Korean, Japanese, Mandarin, etc.)
- No rote learning, no story overload, no history repeat
- Focus: Skills, Logic, Creativity, Life, Career

---

## 🏗️ Structure — Level System (Not Class System)

> Foreign course mein "Class 6, 7, 8" nahi hoga. **Level system** hoga — like games.
> Student apni speed se aage badhe, class se bandha nahi.

| Level | Age Group | Equivalent | Focus |
|-------|-----------|------------|-------|
| Explorer (L1-L3) | 6-8 years | Class 1-3 | Play-based, curiosity, basics |
| Builder (L4-L6) | 9-11 years | Class 4-6 | Skills building, projects, logic |
| Creator (L7-L9) | 12-14 years | Class 7-9 | Deep skills, real-world projects |
| Innovator (L10-L12) | 15-17 years | Class 10-12 | Specialization, portfolio, career |
